# План: Навигация и группировка уведомлений

## Цель
1. Добавить возможность перехода по уведомлению на страницу, откуда пришло уведомление
2. Группировать уведомления из одного чата в раскрывающееся окно с счётчиком

## Изменяемые файлы (9 файлов)

### 1. `notifications_table.sql` — Добавление полей
```sql
ALTER TABLE `notifications` 
ADD COLUMN `group_id` int(11) DEFAULT NULL AFTER `message`,
ADD COLUMN `target_page` varchar(100) DEFAULT NULL AFTER `group_id`,
ADD COLUMN `target_params` text DEFAULT NULL AFTER `target_page`;
```

### 3. `api/send_message.php` — Сохранение данных навигации
При создании уведомления `chat_message`:
- Сохранять `group_id` (для групповых сообщений)
- Сохранять `target_page = "group.html"`
- Сохранять `target_params = {"group_id": X, "open_chat": 1}`

### 6. `api/cancel_application.php` — Сохранение данных навигации

### 8. `profile.html` — Рендеринг и навигация
**Изменения в `loadNotifications()`:**
- Разделить уведомления на сгруппированные и отдельные
- Для сгруппированных: создать accordion с первым сообщением и "+N more"
- Для отдельных: отобразить как есть

**Добавить обработчик клика:**
```javascript
function handleNotificationClick(notif) {
    if (notif.target_page) {
        let url = notif.target_page + '?';
        if (notif.target_params) {
            url += new URLSearchParams(notif.target_params).toString();
        }
        window.location.href = url;
    }
    markNotificationRead(notif.id);
}
```
