# План миграции с Leaflet/OpenStreetMap на Яндекс.Карты

## Контекст
Проект использует Leaflet 1.9.4 + OpenStreetMap tiles + Nominatim/Photon для геокодирования.
Необходимо заменить на Яндекс.Карты API.

## Файлы для изменения

### 1. `admin.html` — Карта выбора точки (map picker)
**Что меняется:**
- Заменить загрузку Leaflet CSS/JS на API ключ Яндекс.Карт (`https://api-maps.yandex.ru/2.1/?apikey=YOUR_API_KEY&lang=ru_RU`)
- Заменить `L.map()` → `ymaps.Map`
- Заменить `L.tileLayer()` → `ymaps.Tile` + `ymaps.TileLayer` (или стандартные стандартные карты Яндекса)
- Заменить `L.marker()` → `ymaps.Placemark`
- Заменить `L.latLng()` → `[lat, lng]` (Яндекс использует тот же формат)
- Заменить `map.on('click', ...)` → `map.events.click`
- Заменить `map.setView()` → `map.setView()` (аналогично)
- Заменить `marker.bindPopup()` → `placemark.properties.set()` + `balloon.open()`
- Заменить `invalidateSize()` → `map.invalidateSize()` (аналогично)
- Заменить обратное геокодирование Nominatim/Photon → `ymaps.geolocation` или `geocode()` API Яндекса
- Заменить поиск адреса → `ymaps.geocode()`

**Ключевые функции:**
- `loadLeafletAsync()` → загрузка Yandex Maps API
- `openMapPicker()` → инициализация `new ymaps.Map('map', {...})`
- Клик по карте → `map.events.click`
- Обратное геокодирование → `ymaps.geocode()` или обратное геокодирование Яндекса
- Поиск адреса → `ymaps.geocode(address)`

### 2. `namahatta.html` — Отображение групп на карте
**Что меняется:**
- Заменить `loadLeaflet()` → загрузка Yandex Maps API
- Заменить `L.map()` → `ymaps.Map`
- Заменить `L.tileLayer()` → стандартные карты Яндекса
- Заменить `L.marker()` → `ymaps.Placemark`
- Заменить `marker.bindPopup()` → `placemark.balloon.open()`
- Заменить кластеризацию (ручная) → `ymaps.Clusterer` (встроенный кластеризатор Яндекса)

**Ключевые функции:**
- `loadLeaflet()` → загрузка Yandex Maps API
- `openMapModal()` → инициализация карты
- Замена ручной группировки на `ymaps.Clusterer`

### 3. `bhaktivriksha.html` — Аналогично namahatta.html

### 4. `style.css` — Стили карты

## Детали реализации

### Подключение API Яндекс.Карт
```html
<!-- Вместо Leaflet -->
<script src="https://api-maps.yandex.ru/2.1/?apikey=YOUR_API_KEY&lang=ru_RU"></script>
```

### Инициализация карты
```javascript
// Было (Leaflet)
const map = L.map('map').setView([lat, lng], 12);
L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png').addTo(map);
const marker = L.marker([lat, lng]).addTo(map);

// Стало (Яндекс)
const map = new ymaps.Map('map', {
    center: [lat, lng],
    zoom: 12
}, { searchControl: false });

const placemark = new ymaps.Placemark([lat, lng], {
    balloonContent: 'Текст'
}, { preset: 'islands#blueDotIcon' });
map.geoObjects.add(placemark);
```

### Кластеризация (namahatta.html, bhaktivriksha.html)
```javascript
// Было: ручная группировка по координатам
// Стало:
const clusterer = new ymaps.Clusterer({
    preset: 'islands#invertedBlueClusterIcons',
    groupByCoordinates: false
});

groups.forEach(group => {
    clusterer.add(new ymaps.Placemark([group.lat, group.lng], {
        balloonContentHeader: group.name,
        balloonContentBody: group.city
    }));
});

map.geoObjects.add(clusterer);
```

### Геокодирование (admin.html)
```javascript
// Было: fetch к Nominatim/Photon
// Стало:
ymaps.geocode('Красноярск, ул. Мира, 15').then(res => {
    res.geoObjects.each(obj => {
        const coords = obj.geometry.getCoordinates();
        // coords = [lat, lng]
    });
});

// Обратное геокодирование
ymaps.geocode(coords, { kind: 'house' }).then(res => {
    res.geoObjects.each(obj => {
        const address = obj.properties.get('text');
    });
});
```

### Кластеризация маркеров
Яндекс.Карты имеют встроенный `ymaps.Clusterer`, который автоматически группирует близкие маркеры — это лучше ручной группировки по координатам.
