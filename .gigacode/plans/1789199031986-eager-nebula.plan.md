# Plan: Telegram-style Message Forwarding

## Problem
Current forward implementation has critical gaps:
1. `forward_sender_id` is passed to API but **NOT stored in database**
2. Forwarded messages show only "📌 Пересланное" without original author info
3. No way to navigate to the original message
4. Missing migration file for `is_forwarded` column

## Solution Overview
Implement full Telegram-style forwarding with:
- Database column for `forward_sender_id`
- Backend stores and returns original sender info
- Frontend shows "📌 Переслано от [Author Name]" 
- Click on forwarded header navigates to original message

**Add new function `navigateToOriginalMessage()`:**

```javascript
/**
 * Navigate to the original message when clicking on forwarded header
 * @param {number} currentMessageId - ID of the forwarded message
 * @param {number|null} originalSenderId - ID of the original sender
 */
function navigateToOriginalMessage(currentMessageId, originalSenderId) {
    // Scroll to the original message in the chat
    const originalMessageEl = document.querySelector(`.chat-msg-row[data-message-id="${currentMessageId}"]`);
    if (originalMessageEl) {
        originalMessageEl.scrollIntoView({ behavior: 'smooth', block: 'center' });
        
        // Highlight the message briefly
        originalMessageEl.classList.add('highlight-message');
        setTimeout(() => {
            originalMessageEl.classList.remove('highlight-message');
        }, 2000);
    } else {
        // Message might be outside current view (older than 100 messages)
        showToast('⚠️ Оригинальное сообщение не найдено в текущей выборке');
    }
}
```
