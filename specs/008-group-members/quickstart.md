# Руководство по быстрой проверке Списка участников (quickstart.md)

Методы верификации нативного экрана и поискового API.

---

## Тест-кейс 1: Валидация API списка участников (Критерий SC-1002)

### Шаг 1: Запуск запроса
Выполните GET запрос через curl:
```bash
curl -X GET http://localhost/api/get_group_members.php?groupId=1
```

### Шаг 2: Проверка данных
- **Ожидаемый результат:** Массив JSON объектов. Убедитесь, что для Лидера приходит заполненное поле `spiritualName` (если есть в БД) и корректная роль.

---

## Тест-кейс 2: Проверка нативного поиска через ADB (Критерий SC-1001, SC-1003)

### Шаг 1: Эмуляция запуска экрана из терминала
```bash
adb shell am start -n com.example.namahatta/.GroupMembersActivity --ei "groupId" 1
```

### Шаг 2: Тестирование поиска
1. После загрузки списка введите в поле поиска начало духовного имени (например, "Иш").
2. **Ожидаемый результат:** Список мгновенно отфильтровался, оставив участника "Ишвара Дас".
3. Удалите текст, введите фамилию (например, "Петр").
4. **Ожидаемый результат:** Список отфильтровался, показав "Алексей Петров".
5. Время реакции интерфейса — визуально мгновенно (< 100 мс).
