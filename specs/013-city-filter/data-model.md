# Модель данных: Фильтр по городам (013-city-filter)

## 1. Спецификация API Контрактов

### А. Список доступных городов (GET /api/get_cities.php)
**Ответ (JSON Массив строк):**
```json
["Москва", "Санкт-Петербург", "Екатеринбург"]
```

### Б. Обновленный контракт получения групп (GET /api/get_groups_coords.php?city={name})
**Поведение:** Если параметр `city` передан, сервер возвращает только те группы, у которых поле `city` точно совпадает со значением.

## 3. SQL логика фильтрации

```sql
-- Пример запроса для групп с фильтром
SELECT * FROM `groups` 
WHERE (:city_param IS NULL OR `city` = :city_param)
  AND `latitude` IS NOT NULL;
```
