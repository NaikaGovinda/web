# Руководство по быстрой проверке Фильтра городов (quickstart.md)

Методы верификации глобальной фильтрации.

---

## Тест-кейс 1: Валидация API городов (Критерий SC-1501)

### Шаг 1: Запрос списка городов
```bash
curl -X GET http://localhost/api/get_cities.php
```
- **Ожидаемый результат:** Массив уникальных названий городов, присутствующих в таблице `groups`.

### Шаг 2: Проверка фильтрации групп
1. Выполните запрос координат без фильтра: `GET /api/get_groups_coords.php`.
2. Выполните запрос с фильтром: `GET /api/get_groups_coords.php?city=Москва`.
- **Ожидаемый результат:** Во втором случае в ответе должны быть только московские группы. Скорость ответа < 400 мс.

---

## Тест-кейс 2: Проверка сохранения выбора (Критерий SC-1502)

1. Откройте приложение, выберите город в выпадающем списке.
2. Перезагрузите страницу в браузере или перезапустите Android-контейнер.
3. **Ожидаемый результат:** Фильтр сохраняет выбранное значение, список групп загружается сразу для этого города.
