# Список задач реализации: Система заявок на вступление в группу (006-group-applications)

Этот документ содержит пошаговый атомарный план разработки системы модерации участников, увязанный с функциональными требованиями (`FR`) и критериями измеряемого успеха (`SC`).

---

## Фаза 1: Разработка СУБД и Бэкенд API

- [ ] **TSK-161 (SQL Расширение: Таблица заявок):** Модифицировать файл `backend/database.sql`, добавив создание таблицы `applications` со статусами и связями.
  - **Файлы:** `backend/database.sql`
  - **Критерий:** СУБД успешно создает таблицу и соблюдает целостность внешних ключей.

- [ ] **TSK-162 (API Подачи заявки):** Реализовать PHP-скрипт `backend/api/apply_to_group.php`. Добавить проверку на дубликаты (нельзя подать две активные заявки в одну группу) и интеграцию с FCM (вызов функции отправки пуша лидеру).
  - **Файлы:** `backend/api/apply_to_group.php`
  - **Связь с требованиями:** `FR-602`, `FR-604`, `SC-803`.

- [ ] **TSK-163 (API Обработки заявок для лидеров):** Реализовать PHP-скрипты `backend/api/get_applications.php` (получение списка) и `backend/api/process_application.php` (одобрение/отклонение). Логика одобрения должна выполнять атомарный `INSERT` в `group_members`.
  - **Файлы:** `backend/api/get_applications.php`, `backend/api/process_application.php`
  - **Связь с требованиями:** `FR-602`, `SC-801`.

---

## Фаза 2: Обновление Веб-интерфейса и Фронтенда

- [ ] **TSK-261 (Интеграция кнопки Подачи в Веб):** Добавить на страницу `backend/group.html` кнопку «Вступить в группу». Реализовать JS-логику: вызов API и отображение статуса «Заявка отправлена».
  - **Файлы:** `backend/group.html`
  - **Связь с требованиями:** `Scenario 1`.

## Фаза 3: Разработка Нативной Активности Android

- [ ] **TSK-361 (Регистрация и Контейнер Активности):** Создать `GroupApplicationsActivity.kt` и зарегистрировать её в `AndroidManifest.xml`. Настроить ViewModel для работы с API заявок.
  - **Файлы:** `android/app/src/main/java/com/example/namahatta/GroupApplicationsActivity.kt`, `android/app/src/main/AndroidManifest.xml`
  - **Связь с требованиями:** `FR-601`.

- [ ] **TSK-362 (Реализация Compose UI Модерации):** Написать интерфейс списка заявок. Использовать `LazyColumn` с `animateItemPlacement()` для визуально плавного удаления карточек при нажатии на кнопки «Одобрить/Отклонить».
  - **Файлы:** `android/app/src/main/java/com/example/namahatta/GroupApplicationsActivity.kt`
  - **Связь с требованиями:** `FR-601`, `SC-802` (Плавность анимаций).
