# Руководство по быстрой проверке Заявок (quickstart.md)

В данном руководстве описаны методы верификации системы модерации.

---

## Тест-кейс 1: Полный цикл модерации (Бизнес-логика)

### Шаг 1: Подача заявки через API
Выполните POST:
```bash
curl -X POST http://localhost/api/apply_to_group.php \
     -H "Content-Type: application/json" \
     -d '{"userId": 2, "groupId": 1}'
```

### Шаг 2: Проверка списка лидером в Android (Эмуляция)
Выполните adb-запуск экрана заявок:
```bash
adb shell am start -n com.example.namahatta/.GroupApplicationsActivity --ei "leaderId" 1
```
- **Ожидаемый результат:** В нативном списке отображается заявка от "Алексей Петров" (ID 2).

### Шаг 3: Одобрение и проверка состава группы
1. Нажмите "Одобрить" в нативном интерфейсе.
2. Проверьте БД:
```sql
SELECT * FROM group_members WHERE user_id = 2 AND group_id = 1;
```
- **Ожидаемый результат:** Создана запись об участии пользователя №2 в группе №1.

---

## Тест-кейс 2: Проверка пуша (Критерий SC-803)
1. Выполните Шаг 1 (Подача заявки).
2. **Ожидаемый результат:** В течение 5 секунд на смартфоне лидера (ID 1) появляется уведомление "Новая заявка в группу".
