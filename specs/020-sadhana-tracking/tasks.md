# Список задач реализации: Отслеживание садханы (020-sadhana-tracking)

Этот документ содержит пошаговый атомарный план разработки. Каждая задача привязана к функциональным требованиям (`FR`) и измеряемым критериям успеха (`SC`), описанным в спецификации.

---

## Фаза 0: Миграции Базы Данных

- [ ] **TSK-001 (Миграция таблиц садханы):** Создать SQL-файл миграции `migrations/020_create_sadhana_tables.sql` с таблицами `sadhana_cards`, `sadhana_daily_logs`, `sadhana_sleep_logs`. Определить индексы по `(user_id, date)` для быстрого поиска.

  - **Связь с требованиями:** `FR-203`, `FR-201`, `FR-202`

## Фаза 1: Авторизация и привязка к пользователю

- [ ] **TSK-100 (Получение USER_ID из сессии):** Заменить захаркоженный `USER_ID = 'NaikaGovinda'` на динамическое получение из текущей сессии. Создать функцию `getCurrentUserId()` которая:
  - Проверяет localStorage на наличие токена авторизации (`auth_token` или аналог)
  - Если токен есть — делает запрос к `api/check_auth.php` или `api/get_profile.php` для получения user_id
  - Если авторизации нет — показывает модальное окно «Войдите в профиль» или редиректит на `/login.html`
  - **Файлы:** `sadhana.html`, `sadhana-cards.html`
  - **Связь с требованиями:** `FR-208`, `SC-405`

- [ ] **TSK-101 (Проверка авторизации при загрузке):** При открытии страницы садханы проверять авторизацию до рендеринга контента. Если пользователь не авторизован — показывать экран «Необходимо войти в профиль» с кнопкой перехода на `/login.html`.
  - **Файлы:** `sadhana.html`, `sadhana-cards.html`
  - **Связь с требованиями:** `FR-208`, `SC-405`

## Фаза 2: Backend API

- [ ] **TSK-201 (Структура API садханы):** Создать директорию `api/sadhana/`. Подготовить базовый файл `api/sadhana/index.php` с роутингом запросов и middleware для валидации `X-User-Id` заголовка.
  - **Файлы:** `api/sadhana/index.php`, `api/sadhana/middleware.php`
  - **Связь с требованиями:** `FR-206`

- [ ] **TSK-202 (CRUD карточек):** Реализовать endpoints:
  - `GET /api/sadhana/cards` — выборка карточек пользователя (не архивных)
  - `POST /api/sadhana/cards` — создание карточки (валидация name, type, targetValue, unit)
  - `PATCH /api/sadhana/cards/{id}/archive` — архивирование (set is_archived=1)
  - **Файлы:** `api/sadhana/cards.php`
  - **Связь с требованиями:** `FR-203`, `FR-206`

- [ ] **TSK-203 (Логирование практик):** Реализовать endpoint:
  - `POST /api/sadhana/cards/{cardId}/logs` — сохранение/обновление дневного лога (actualValue, books JSON)
  - Валидация: cardId принадлежит пользователю, date не пустая
  - **Файлы:** `api/sadhana/logs.php`
  - **Связь с требованиями:** `FR-201`, `FR-206`

- [ ] **TSK-204 (Логирование сна):** Реализовать endpoint:
  - `POST /api/sadhana/sleep` — сохранение/обновление лога сна (date, bedTime, wakeTime)
  - Валидация: формат времени HH:MM:SS
  - **Файлы:** `api/sadhana/sleep.php`
  - **Связь с требованиями:** `FR-202`, `FR-206`
