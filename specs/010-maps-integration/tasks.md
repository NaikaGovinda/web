# Список задач реализации: Интеграция Карт (010-maps-integration)

Этот документ содержит пошаговый атомарный план разработки карты групп, увязанный с функциональными требованиями (`FR`) и критериями измеряемого успеха (`SC`).

---

## Фаза 1: Подготовка СУБД и Бэкенд API

- [ ] **TSK-1101 (SQL: Поля координат):** Модифицировать файл `backend/database.sql`, добавив колонки `latitude` и `longitude` в таблицу `groups`. Добавить тестовые координаты.
  - **Файлы:** `backend/database.sql`

- [ ] **TSK-1102 (API Гео-данных):** Реализовать серверный PHP-скрипт `backend/api/get_groups_coords.php`. Выбрать ID, название и координаты всех активных групп.
  - **Файлы:** `backend/api/get_groups_coords.php`
  - **Связь с требованиями:** `FR-1003`.

---

## Фаза 2: Реализация Веб-Интерфейса Карты

- [ ] **TSK-1201 (Верстка страницы Карты):** Создать файл `backend/map.html`. Подключить скрипт Яндекс.Карт и `android-hybrid-core.js`.
  - **Файлы:** `backend/map.html`

- [ ] **TSK-1202 (Инициализация ymaps и кластеризатора):** Написать JS-логику загрузки данных из API и отрисовки меток на карте с использованием `ymaps.Clusterer`.
  - **Файлы:** `backend/map.html`
  - **Связь с требованиями:** `FR-1001`, `FR-1002`.

- [ ] **TSK-1203 (Интеграция Балунов с Мостом):** Реализовать шаблон балуна с кнопкой «Подробнее», вызывающей `window.openNativeGroupDetails(groupId)`.
  - **Файлы:** `backend/map.html`
  - **Связь с требованиями:** `Scenario 3`, `SC-1203`.

---

## Фаза 3: Верификация

- [ ] **TSK-1301 (Тестирование жестов и скорости):** Проверить работу карты в Android WebView: плавность зума и перемещения. Убедиться, что время загрузки соответствует `SC-1201`.
  - **Связь с требованиями:** `FR-1004`.
