# Руководство по быстрой проверке Карт (quickstart.md)

Методы верификации интеграции Яндекс.Карт.

---

## Тест-кейс 1: Валидация API координат (Критерий SC-1202)

### Шаг 1: Запрос данных
Выполните GET запрос через curl:
```bash
curl -X GET http://localhost/api/get_groups_coords.php
```

### Шаг 2: Проверка точности
- **Ожидаемый результат:** JSON массив с числовыми значениями `lat` и `lng`. Убедитесь, что координаты соответствуют вставленным в БД значениям.

---

## Тест-кейс 2: Проверка интерактивности в WebView (Критерий SC-1203)

1. Откройте Android приложение на странице `map.html`.
2. Дождитесь загрузки Яндекс.Карт.
3. Нажмите на метку любой группы.
4. **Ожидаемый результат:** В течение 150 мс открывается балун с текстом "Лидер: ...".
5. Нажмите кнопку «Подробнее» внутри балуна.
6. **Ожидаемый результат:** Нативный контейнер перехватывает вызов и открывает `GroupDetailActivity` для этой группы.
