# Спецификация: Интеграция Яндекс.Карт и Карта групп (010-maps-integration)

## Обзор и контекст
Карта групп является визуальным инструментом для поиска ближайших сообществ Namahatta. Пользователи должны иметь возможность видеть метки всех активных групп в своем городе на интерактивной карте, просматривать краткую информацию о группе при нажатии на метку и переходить к деталям. Реализация выполняется в гибридном веб-интерфейсе с использованием API Яндекс.Карт для обеспечения актуальности картографических данных и единого вида на всех устройствах.

## Пользовательские сценарии и сценарии приемки
### Сценарий 1: Отображение карты с группами
- **Дано:** Авторизованный пользователь открывает раздел «Карта» в веб-интерфейсе.
- **Когда:** Страница инициализируется.
- **Тогда:** Система должна загрузить библиотеку Яндекс.Карт и отобразить карту, центрированную на городе пользователя (или дефолтном значении).
- **И:** Все группы из базы данных должны отобразиться в виде меток (плацемарков) на карте.

### Сценарий 2: Просмотр балуна с информацией о группе
- **Дано:** Пользователь видит метку группы на карте.
- **Когда:** Он нажимает на метку.
- **Тогда:** Над меткой должен открыться балун (всплывающее окно) с названием группы, именем лидера и кнопкой «Подробнее».

### Сценарий 3: Переход к деталям группы с карты
- **Дано:** Открыт балун группы на карте.
- **Когда:** Пользователь нажимает кнопку «Подробнее» внутри балуна.
- **Тогда:** Приложение должно перенаправить пользователя на страницу деталей группы (с учетом гибридного перехвата в нативный экран, если активно мобильное приложение).

## Функциональные требования
- **FR-1001 (Интеграция Yandex Maps JS API):** Использование версии 2.1 или 3.0 API Яндекс.Карт для рендеринга интерактивного слоя.
- **FR-1002 (Кластеризация меток):** При большом скоплении групп в одной области метки должны автоматически объединяться в кластеры для сохранения чистоты интерфейса.
- **FR-1003 (API гео-данных):** Бэкенд должен предоставлять эндпоинт `api/get_groups_coords.php`, возвращающий массив объектов с ID, координатами (lat, lng), названием и именем лидера.
- **FR-1004 (Адаптация под WebView):** Карта должна корректно обрабатывать тач-события (зум, перемещение) внутри мобильного контейнера Android без конфликтов со скроллингом страницы.

## Критерии успеха (измеряемые и технологически независимые)
- **SC-1201 (Скорость рендеринга):** Карта с метками должна быть полностью готова к взаимодействию в течение не более 3 секунд после открытия страницы при 3G-соединении.
- **SC-1202 (Точность позиционирования):** Все метки должны соответствовать координатам, указанным в базе данных, с точностью до 5 метров.
- **SC-1203 (Отзывчивость балуна):** Время от клика на метку до появления окна с информацией не должно превышать 150 мс.

## Допущения и границы системы
- Для работы карты требуется активный API-ключ Яндекс.Карт, прописанный в конфигурации.
- Координаты групп (широта и долгота) уже должны присутствовать в таблице `groups`.
- **Вне рамок спецификации:** Определение геолокации пользователя по GPS, фильтрация по категориям групп на карте.
