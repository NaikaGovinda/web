# Список задач реализации: Веб-ядро и Бэкенд API (003-web-backend-core)

Этот документ содержит пошаговый атомарный чек-лист задач для развертывания веб-инфраструктуры, увязанный с функциональными требованиями (`FR`) и критериями измеряемого успеха (`SC`).

---

## Фаза 1: Подготовка Базы Данных и Конфигурации Сервера

- [x] **TSK-121 (SQL Инициализация СУБД):** Создать SQL-скрипт `backend/database.sql` с разметкой создания таблицы `users`, включающей поле `fcm_token` (VARCHAR(255)) под функциональное требование `FR-303`.
  - **Файлы:** `backend/database.sql`
  - **Критерий:** Файл содержит валидный синтаксис SQL InnoDB.

- [x] **TSK-122 (Скрипт Подключения к БД):** Написать серверный конфигурационный скрипт подключения к базе данных `backend/config/database.php` и `backend/api/db.php` с использованием безопасного расширения PDO для предотвращения SQL-инъекций.
  - **Файлы:** `backend/config/database.php`, `backend/api/db.php`
  - **Критерий:** Скрипт корректно экспортирует объект подключения к СУБД.

---

## Фаза 2: Реализация Фронтенд Модуля интеграции моста

- [x] **TSK-221 (Модуль Нативного Моста на JS):** Реализовать фронтенд-скрипт `backend/js/android-hybrid-core.js` и `backend/android.js`. Прописать автоматическое определение `window.AndroidBridge`.
  - **Файлы:** `backend/js/android-hybrid-core.js`, `backend/android.js`
  - **Связь с требованиями:** `FR-301`.

- [x] **TSK-222 (Адаптация UI под гибридный режим):** Добавить в `android-hybrid-core.js` логику переключения стилей интерфейса. Если мост обнаружен, вешать класс `.hybrid-mode` на тег `<body>` для CSS-скрытия веб-шапок и навигации.
  - **Файлы:** `backend/js/android-hybrid-core.js`
  - **Связь с требованиями:** `SC-502` (Скорость адаптации верстки < 50мс).
