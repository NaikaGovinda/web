# Руководство по быстрой проверке Веб-ядра и API (quickstart.md)

В данном руководстве приведены сценарии ручной верификации серверных эндпоинтов и фронтенд-скриптов адаптации гибридного интерфейса.

---

## Тест-кейс 1: Валидация API сохранения токенов (Критерий SC-501)

Для проверки эндпоинта без мобильного приложения используется отправка сырого HTTP-запроса (например, через встроенный REST-клиент или curl):

### Шаг 1: Выполнение запроса привязки токена
Выполните POST запрос к развернутому эндпоинту:
```bash
curl -X POST http://localhost/api/update_user_fcm_token.php \
     -H "Content-Type: application/json" \
     -d '{"userId": "1", "fcm_token": "test_token_12345"}'
```

### Шаг 2: Проверка ответа сервера
- **Ожидаемый результат (HTTP 200):** Сервер мгновенно (в пределах критерия `SC-501` — 200мс) возвращает валидный JSON:
  ```json
  {"status":"success","message":"Token successfully synchronized"}
  ```

### Шаг 3: Проверка записи в базе данных
Выполните контрольный SQL-запрос к таблице `users` в СУБД:
```sql
SELECT fcm_token FROM users WHERE id = 1;
```
- **Ожидаемый результат:** Поле `fcm_token` для пользователя с `id = 1` содержит значение `"test_token_12345"`.

## Тест-кейс 2: Проверка адаптации UI фронтенда (Критерий SC-502)

### Шаг 1: Эмуляция гибридного режима в браузере ПК
1. Откройте страницу `index.html` в обычном браузере.
2. В консоли разработчика (F12) введите команду инъекции мока моста:
   ```javascript
   window.AndroidBridge = {};
   ```
3. Перезагрузите или обновите страницу локально.
4. **Ожидаемый результат:** Скрипт `android-hybrid-core.js` мгновенно (в пределах `SC-502` — 50мс) определяет наличие объекта, вешает на тег `<body>` класс `.hybrid-mode`, который через CSS скрывает веб-шапки и панели скачивания посторонних файлов. Интерфейс адаптируется под мобильный контейнер.
