# Руководство по быстрой проверке пуш-уведомлений (quickstart.md)

В данном руководстве описаны методы отладки и ручной проверки критериев успеха системы уведомлений с помощью встроенного отладчика Android Debug Bridge (`adb`).

---

## Тест-кейс 1: Проверка умного подавления уведомлений (Критерий SC-402)

### Шаг 1: Эмуляция активного чата через консоль JS
1. Откройте приложение на устройстве. В консоли инспектирования WebView (или через тестовую кнопку) выполните вызов моста:
   ```javascript
   window.AndroidBridge.setActiveChat('{"activeChatId":"555"}');
   ```
2. **Ожидаемый результат:** Нативный контейнер зафиксировал контекст чата `555`.

### Шаг 2: Симуляция входящего пуша из этого же чата
1. Выполните adb-команду для отправки интента службы (эмуляция входящего FCM пакета):
   ```bash
   adb shell am startservice -n com.example.namahatta/.core.services.MyFirebaseMessagingService --es "action" "mock_receive" --es "chatId" "555" --es "title" "Тест" --es "body" "Игнорируй меня"
   ```
2. **Ожидаемый результат:** Нативная служба перехватила сообщение, увидела совпадение ID чата (`555` == `555`), подавила отображение. В системной шторке уведомление **НЕ появилось**. В логах отображается строка подавления.

### Шаг 3: Симуляция входящего пуша из другого чата
1. Выполните adb-команду с другим ID чата:
   ```bash
   adb shell am startservice -n com.example.namahatta/.core.services.MyFirebaseMessagingService --es "action" "mock_receive" --es "chatId" "777" --es "title" "Важное событие" --es "body" "Появись в шторке"
   ```
2. **Ожидаемый результат:** ID чата не совпадает (`777` != `555`). В системной шторке мгновенно **появляется баннер** уведомления с заголовком "Важное событие".

## Тест-кейс 2: Проверка глубокой маршрутизации по URL (Критерий SC-401)

### Шаг 1: Клик по уведомлению
1. Нажмите на появившееся в шторке уведомление "Важное событие".
2. **Ожидаемый результат:** Уведомление исчезает из шторки. Нативный контейнер перехватывает клик, извлекает встроенный `targetUrl` и вызывает принудительную перенавигацию движка. WebView мгновенно (в пределах `SC-401` — 300мс) начинает загрузку страницы группы/события.
