# Руководство по быстрой проверке Напоминаний (quickstart.md)

Методы верификации работы Cron-задачи.

---

## Тест-кейс 1: Верификация точности выборки (Критерий SC-1401)

### Шаг 1: Подготовка данных
Вставьте тестовое мероприятие, которое начнется ровно через 60 минут:
```sql
SET @target_time = NOW() + INTERVAL 60 MINUTE;
INSERT INTO `events` (group_id, title, event_date) VALUES (1, 'Тест Напоминания', @target_time);
INSERT INTO `event_participants` (event_id, user_id, reminder_sent) VALUES (LAST_INSERT_ID(), 1, 0);
```

### Шаг 2: Запуск скрипта
Запустите скрипт напоминаний вручную:
```bash
php backend/cron/send_reminders.php
```

### Шаг 3: Проверка результата
1. **Логи:** В логах сервера должна появиться запись об отправке пуша пользователю ID 1.
2. **БД:** `SELECT reminder_sent FROM event_participants WHERE user_id = 1` должен стать `1`.
3. **Смартфон:** В шторке уведомлений Android должно появиться сообщение: "Скоро начнется встреча!".

---

## Тест-кейс 2: Защита от дублей (Критерий SC-1402)
1. Снова запустите `php backend/cron/send_reminders.php`.
2. **Ожидаемый результат:** Скрипт не должен находить новых записей, повторный пуш **не должен** прийти.
