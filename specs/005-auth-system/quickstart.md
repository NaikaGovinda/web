# Руководство по быстрой проверке Авторизации (quickstart.md)

В данном руководстве описаны шаги для ручной верификации работы системы регистрации и входа.

---

## Тест-кейс 1: Проверка безопасности хранения паролей (Критерий SC-701)

### Шаг 1: Регистрация нового пользователя
Выполните POST запрос через curl:
```bash
curl -X POST http://localhost/api/register.php \
     -H "Content-Type: application/json" \
     -d '{"name": "Безопасный Тест", "email": "sec@test.ru", "password": "mypassword"}'
```

### Шаг 2: Проверка записи в базе данных
Выполните SQL запрос:
```sql
SELECT password_hash FROM users WHERE email = 'sec@test.ru';
```
- **Ожидаемый результат:** Значение в поле `password_hash` должно начинаться с `$2y$` (хеш Bcrypt). Исходное значение `"mypassword"` **не должно** присутствовать в базе.

## Тест-кейс 2: Проверка синхронизации с Android мостом (Критерий SC-703)

### Шаг 1: Вход через мобильный WebView
1. Запустите Android приложение, перейдите на страницу `login.html`.
2. Введите верные учетные данные и нажмите «Войти».
3. **Ожидаемый результат:** После получения JSON ответа от сервера, скрипт вызывает нативный мост. На экране смартфона должен появиться Toast: "Пользователь синхронизирован".
