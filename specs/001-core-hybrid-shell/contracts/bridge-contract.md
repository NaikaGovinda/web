# Контракт интерфейса: WebAppInterface

Этот документ фиксирует двунаправленный контракт взаимодействия между веб-приложением (JavaScript) и нативным Android-клиентом. Изменения в этих сигнатурах запрещены без пересмотра технического плана фичи.

Объект моста регистрируется в глобальном контексте браузера под именем `window.AndroidBridge`.

---

## 1. Вызовы из JavaScript в Android (Входящие для Android)

### `setUser(sessionJson: String): void`
Вызывается веб-приложением после успешной авторизации пользователя или при обновлении токенов.
- **Аргументы:** Строка JSON, соответствующая схеме `UserSession` (см. `data-model.md`).
- **Поведение нативного клиента:** Сохраняет сессионные данные в зашифрованное локальное хранилище контейнера.

### `openGallery(): void`
Вызывается веб-приложением, когда пользователь нажимает кнопку прикрепления фото или изменения аватара.
- **Аргументы:** Отсутствуют.
- **Поведение нативного клиента:** Прерывает стандартную обработку браузера, запускает системный `PickVisualMedia` контракт. После выбора файла конвертирует его в Base64 или временный Blob-URI и отправляет обратно через ответный вызов (см. раздел 2).

### `setActiveChat(chatContextJson: String): void`
Вызывается веб-приложением, когда пользователь заходит в окно конкретного диалога или группы.
- **Аргументы:** Строка JSON, соответствующая схеме `ChatContext` (см. `data-model.md`).
- **Поведение нативного клиента:** Обновляет внутренний стейт приложения для подавления или кастомизации пуш-уведомлений от этого конкретного чата.

---

## 2. Вызовы из Android в JavaScript (Исходящие для Android / Колбэки)

Вызовы осуществляются нативным клиентом путем выполнения JavaScript-кода через метод `webView.evaluateJavascript()`.

### `window.onImageSelected(base64Data: String, mimeType: String): void`
Передает выбранное нативное изображение обратно в веб-интерфейс для отображения или отправки на сервер.
- **Аргументы:**
  - `base64Data`: Строка данных изображения в кодировке Base64.
  - `mimeType`: Строка типа контента (например, `"image/jpeg"`, `"image/png"`).

### `window.onNativeBackPressed(): boolean`
Вызывается нативным клиентом, когда пользователь нажал аппаратную кнопку «Назад» на телефоне.
- **Возвращаемое значение (через колбэк evaluate):**
  - `true`: Веб-приложение обработало нажатие внутри себя (например, закрыло модальное окно или перешло на прошлую внутреннюю вкладку). Нативный контейнер ничего не делает.
  - `false`: У веб-приложения нет внутренней истории или открытых окон для закрытия. Нативный контейнер выполнит стандартное поведение (свернет приложение).
