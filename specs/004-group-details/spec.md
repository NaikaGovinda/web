# Спецификация: Детали группы и Навигация из списка (004-group-details)

## Обзор и контекст
Экран деталей группы (`group.html`) является центральным узлом для просмотра профиля группы (описание, ведущие, расписание, галерея фотографий, участники, подача заявок). При клике на карточку группы в списке Нама-Хатт (`namahatta.html`) пользователь должен попадать именно в профиль группы (`group.html?id=...`), а не в чат. Списки групп и детальные страницы поддерживают вертикальный скролл (`content-scroll`) для удобства навигации на любых мобильных устройствах.

## Пользовательские сценарии и сценарии приемки
### Сценарий 1: Переход из списка в профиль группы
- **Дано:** Пользователь находится на странице списка групп (`namahatta.html`).
- **Когда:** Пользователь кликает по карточке любой группы.
- **Тогда:** Происходит переход на страницу профиля группы (`group.html?id=groupId`) с загрузкой полной информации.

### Сценарий 2: Вертикальный скроллинг списка групп
- **Дано:** Пользователь просматривает длинный список найденных групп.
- **Когда:** Пользователь прокручивает страницу вертикально.
- **Тогда:** Список плавно скроллится благодаря контейнеру со стилями прокрутки (`content-scroll`).

## Функциональные требования
- **FR-401 (Навигация из списка в профиль):** Клик по карточке группы в `namahatta.html` перенаправляет на `group.html?id=${group.id}`.
- **FR-402 (Вертикальная прокрутка списка):** Контейнеры списков групп и деталей имеют класс `.content-scroll` для обеспечения корректного скроллинга.
- **FR-403 (Профиль группы и Чат):** Страница `group.html` отображает карточку группы, контакты лидера, галерею и участников, а чат доступен через отдельную кнопку/модальное окно.

## Критерии успеха
- **SC-601:** Клик по группе ведет в профиль (`group.html`), а не в чат.
- **SC-602:** Списки групп и детальная страница группы имеют полноценный вертикальный скроллинг.
