# Контракт интерфейса: Расширение Моста Деталей Группы

Этот документ расширяет глобальный контракт взаимодействия `window.AndroidBridge` новыми сигнатурами вызовов для перенаправления пользователя из веб-навигации на нативный экран карточки группы.

---

## 1. Вызовы из JavaScript в Android (Входящие для контейнера)

### `openGroupDetails(groupId: number): void`
Вызывается веб-приложением при клике пользователя на карточку группы в общем списка, вместо стандартного перехода на другую html-страницу.

- **Аргументы:**
  - `groupId`: Положительное целое число, уникальный ID группы Намахатты в базе данных.
- **Поведение нативного клиента:** Прерывает выполнение веб-скрипта, собирает нативный `Intent` с передачей ключа `groupId` во Extra-параметры и запускает `GroupDetailActivity` (`FR-401`).

---

## 2. Обновленное поведение разметки Фронтенда
Каждая ссылка вида `<a href="group.html?id=125">` на главной странице при активации гибридного режима (`body.classList.contains('hybrid-mode')`) должна блокировать событие перехода (`event.preventDefault()`) и вызывать функцию `window.AndroidBridge.openGroupDetails(125)`.
